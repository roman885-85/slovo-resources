# Ресурси «Слова»

Переклади Біблії, пісенники, фони, шаблони слайдів і сторінки веб-слайдів
для програми [«Слово»](https://github.com/roman885-85/slovo) — окремо від
самої програми.

- `catalog.json` — перелік ресурсів: рід, назва, розмір, версія (дата),
  адреса файла.
- Файли — у розділі [Releases](../../releases): по одному zip на переклад чи
  пісенник, по одному на фони, шаблони, шрифти й сторінки.

Програма читає каталог сама: меню «Настройка» → «Ресурси з GitHub…» —
вибрати, що завантажити; там же — оновлення вже встановленого. Друге
джерело перекладів у тому ж вікні — модулі
[«Цитата з Біблії»](https://github.com/BibleQuote/BibleQuote-Modules).

Пісенники — у форматі «Слова» `.songbook` (JSON); переклади — у форматі
«Цитата з Біблії» (тека з `bibleqt.ini`) або MyBible (`.SQLite3`).
